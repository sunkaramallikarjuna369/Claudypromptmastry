## 🎯 What Is This?

A **complete, hands-on learning platform** that teaches you how to leverage **Claude Opus 4.6** for real-world data engineering tasks — ETL automation, data cleaning, infrastructure-as-code, agentic workflows, and more.

**Who is this for?**
- GCP/DevOps engineers wanting to add AI-powered data engineering to their toolkit
- Beginners in Claude/LLM prompting who learn best by doing
- Anyone who wants production-ready prompt templates for data pipelines

**What will you learn?**
- Claude 4.6's data engineering capabilities (ETL, anomaly detection, Terraform, BigQuery)
- Advanced prompt engineering (Chain-of-Thought, JSON schemas, parallel tool calling)
- API integration (Anthropic, AWS Bedrock, Google Vertex AI)
- Building agentic multi-day data pipeline workflows
- Evaluation frameworks and production runbooks

**Why Claude Opus 4.6?**
- 1M token context window for massive dataset analysis
- Native tool calling for BigQuery, APIs, and file operations
- Agentic mode for multi-step, multi-day project execution
- Best-in-class code generation for Spark, Pandas, SQL, Terraform

**How to use this repo?**
- Follow the 7-day learning path below
- Each module has interactive HTML dashboards + quizzes
- Copy-paste prompt templates directly into your Claude workflows

## ⚡ Quickstart (5 Minutes)

### Prerequisites
- Node.js 18+ installed
- A text editor (VS Code recommended)
- (Optional) Anthropic API key for live demos

### Setup

```bash
# Clone the repository
git clone https://github.com/sunkaramallikarjuna369/Claudypromptmastry.git
cd Claudypromptmastry

# Install dev dependencies
npm install

# Start the development server
npm start
```

Open [http://localhost:5173](http://localhost:5173) in your browser to see the interactive dashboard.

### Quick Demo (No API Key Needed)

1. Open the dashboard at `localhost:5173`
2. Navigate to **Module 01 - Claude Threats**
3. Explore the interactive ETL threat matrix
4. Try the built-in mock Claude API playground
5. Take the 10-question quiz to test your knowledge
