Production Runbook

Step 1: Pre-flight Check
Required
• Verify source data availability (S3/GCS buckets accessible)
• Check BigQuery quotas and slot availability
• Validate Claude API health (ping endpoint)
• Confirm environment variables set correctly
Step 2: Extract
Automated
• Pull data from source systems (S3, APIs, databases)
• Log record counts for each source
• Validate schema consistency against expected format
• Store raw data in staging bucket
Step 3: Transform (Claude-Assisted)
AI-Powered
• Send data profile to Claude for analysis
• Apply Claude-generated cleaning rules
• Execute transformations (joins, aggregates, SCD)
• Log transformation metrics (rows in/out, latency)
Step 4: Load
Critical
• Write to BigQuery staging tables
• Run data quality checks on staged data
• Promote to production tables if checks pass
• Update table metadata and documentation
Step 5: Post-Validation & Alerting
Monitoring
• Compare row counts (source vs target, delta < 1%)
• Check null rates (< threshold per column)
• Validate business rules (revenue non-negative, etc.)
• Send alerts via Slack/PagerDuty if thresholds breached
